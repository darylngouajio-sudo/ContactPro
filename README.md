# ContactPro

Application mobile de gestion des contacts professionnels développée avec .NET MAUI et C#.

## Présentation

ContactPro vise à faciliter l'organisation des contacts professionnels et le suivi des échanges grâce à plusieurs rubriques.

## Fonctionnalités disponibles

- Écran d'accueil et navigation entre les rubriques
- Pages Contacts, Groupes, Notes et Rappels
- Interface testée sur Android et ordinateur

## Technologies utilisées

- C#
- .NET MAUI
- XAML
- Git et GitHub

## État du projet

Il s'agit d'un prototype fonctionnel en cours de développement. Les fonctionnalités principales sont représentées par des pages navigables, mais certaines fonctions restent à compléter.

## Améliorations prévues

- Stockage permanent des données
- Gestion complète des contacts et des groupes
- Recherche et filtrage
- Export des contacts au format vCard
- Notifications système pour les rappels

## Installation et lancement

1. Installer Visual Studio avec la charge de travail .NET MAUI.
2. Cloner ou télécharger ce dépôt GitHub.
3. Ouvrir le fichier `contactpro.csproj` dans Visual Studio.
4. Restaurer les dépendances, puis sélectionner une cible compatible (Android ou Windows) et lancer le projet.
